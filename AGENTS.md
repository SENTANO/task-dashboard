# AGENTS.md — task-dashboard

## Контекст проекта

Принадлежность `task-dashboard` к WST пока не подтверждена владельцем, поэтому не
объединяй его с WST автоматически. В каталоге проектов он временно находится в
группе `unclassified` вместе с `task-bot`. Репозиторий публичный — не помещай сюда
внутренние сведения о приватных проектах, доступах или инфраструктуре.

## Xerj: сначала поиск, потом реализация

До нетривиального кода или архитектурного решения вызови `code_search` с
`group="unclassified"` либо `source="task-dashboard"`. Если локальный `rsearch`
доступен, эквивалентный вызов:

```bash
rsearch -g unclassified -j 'english technical keywords'
```

До обновления XERJ rc.15 используй только ASCII-запросы. Проверь найденное в
исходном файле, соблюдай право `use` и цитируй `источник/путь:строка` в коммите.
Если поиск недоступен, продолжай и явно укажи это в отчёте.
